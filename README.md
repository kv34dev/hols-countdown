# Holidays Countdown

A simple retro-style LED countdown that shows how much time is left until the upcoming holidays — **December 20**.  
This countdown is specifically made to track the start of my lil bros holidays.  
The timer updates in real time and is fully responsive, including support for mobile devices such as iPhones.

## Features

- Counts down to **December 20**
- Displays **days, hours, minutes, and seconds**
- Retro **2000s LED digital clock** design
- Fully responsive layout (mobile-friendly)
- Real-time updating every second
- Includes Arabic title text

## Built with

- **HTML**
- **CSS**
- **JavaScript**
